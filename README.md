# 시험 맞춤 암기 도우미

> 많이 공부하는 것이 아니라, 시험에 필요한 만큼 정확하게 공부한다.

강의 자료(PDF·PPTX·TXT)와 시험 정보(출제 유형·난이도·목표)를 입력하면, AI가 **자료에 있는 내용만으로** 핵심 개념을 뽑아
**필수 암기 / 선택 학습**으로 나누고, 시험 유형에 맞춘 암기 카드·빈칸 암기·실전 테스트·오답 복습을 제공하는 개인용 웹앱입니다.

## 전체 흐름 한눈에 보기

```
[1] 자료 업로드 → [2] 시험 설정 → [3] AI 전략·개념 생성 → [4] 암기(요약·카드·빈칸)
      → [5] 실전 테스트 → [6] 취약 개념 복습 → 진행률 확인
```

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 홈 | `/` | 학습 세트 목록, 전체 진행률, 새 자료 추가 |
| 시험 설정 | `/new` | 파일 업로드, 출제 유형(+비중), 학습 목표, 난이도, 추가 정보 |
| 학습 | `/set/[id]` | AI 분석, 대시보드, 학습 전략, 핵심 요약 / 암기 카드 / 빈칸 암기 / 실전 테스트 |
| 복습 | `/set/[id]/review` | 취약 개념, 오답 목록, 취약 개념만 테스트 |

기존 "CIT 대본 암기카드" 페이지는 `public/legacy/`로 옮겨져 있으며 `/legacy/index.html`에서 그대로 열립니다.

## Claude 아티팩트 버전

`artifact/exam-helper.html`은 같은 기능을 claude.ai 아티팩트 한 페이지로 옮긴 버전입니다.
서버나 API Key 없이 아티팩트의 Claude 호출 기능(sample)으로 분석·문제 생성·채점을 하고,
학습 기록은 내 계정 전용 저장소(db, `data/users/<내 id>/`)에 저장합니다. 파일은 브라우저에서 읽고 추출한 글자만 저장합니다.

- 게시 주소: https://claude.ai/artifact/FYkDNN29ey57fX4NnrmCZw (비공개, 소유자만 열람)

## 실행 방법

필요: Node.js 20 이상

```bash
npm install
cp .env.example .env.local     # 그리고 .env.local 에 API Key 입력
npm run dev                    # http://localhost:3000
```

배포용 실행: `npm run build && npm run start`

### 환경변수 (`.env.local`)

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 예 | [console.anthropic.com](https://console.anthropic.com/settings/keys)에서 발급. 서버에서만 읽으며 브라우저로 전달되지 않습니다. |
| `ANTHROPIC_MODEL` | 아니오 | 기본 `claude-opus-5-5`. 비용을 줄이려면 `claude-sonnet-5-5` / `claude-haiku-5-5`. |

키가 없으면 화면 상단에 설정 안내가 표시되고, AI 기능 호출 시 안내 메시지가 나옵니다.
환경변수를 바꾼 뒤에는 서버를 다시 시작하세요.

## API 사용 비용 안내

AI는 다음 경우에만 호출됩니다(호출마다 요금 발생).

- **자료 분석**: 자료를 약 3만 자 단위 구간으로 나눠 구간당 1회 (시험 설정 화면에 예상 호출 수 표시)
- **문제 생성**: "문제 생성" 1회당 1회
- **채점**: 약술형·서술형 답안, 그리고 단답형 답이 정답과 글자가 다를 때(동의어 판단) 1회
  - 객관식·OX와 정확히 일치하는 단답형은 브라우저에서 바로 채점(무료)

## 주요 기능과 동작 원리

- **자료 처리**: PDF는 페이지별, PPTX는 슬라이드별, TXT는 약 3천 자 구간별로 텍스트를 추출해 각 개념에 `p.3`, `슬라이드 5` 같은 출처를 연결합니다.
  텍스트가 거의 없는 페이지(이미지·스캔본)는 경고로 알려주며, 전체가 이미지인 파일은 업로드 단계에서 안내합니다. 구버전 `.ppt`는 PDF/PPTX로 변환해 올려야 합니다.
- **AI 맞춤 전략**: 출제 유형(객관식=정의·비교, 단답형=키워드, 약술형=2~3문장 모범답안, 서술형=답안 구조), 난이도, 목표, 교수님 강조·기출 정보를 함께 반영해 학습량과 깊이를 조절합니다.
  출제 여부를 단정하지 않고 우선순위로만 제시합니다.
- **AI 응답 검증**: 모든 AI 응답은 JSON 스키마(구조화 출력, `src/lib/schemas.ts`)로 받고 검증합니다. 문제는 존재하는 개념 id인지, 객관식 정답이 보기 안에 있는지 추가 확인합니다.
- **암기 상태**
  - 미암기 → 테스트/자기평가 → 복습 필요 / 암기 완료
  - **암기 완료는 테스트로만** 결정됩니다: 틀린 적 없는 개념은 1번, 틀린 적 있으면 연속 2번 맞혀야 완료.
  - "알고 있음" 자기평가만으로는 완료 처리되지 않습니다. "헷갈림/모름"은 복습 목록에 추가됩니다.
  - 덜 외운 개념(오답 많음, 헷갈림)이 문제·카드에 먼저 나오고, 반복해서 맞힌 개념은 우선순위가 내려갑니다.
- **기본 학습 방식**: 비중이 가장 큰 유형 기준 — 객관식/OX → 암기 카드, 단답형/빈칸 → 빈칸 암기, 약술/서술형 → 핵심 요약.
- **저장**: 모든 학습 데이터는 브라우저 IndexedDB에 저장되어 새로고침해도 유지됩니다(회원가입·DB 서버 없음). 브라우저 데이터를 지우면 함께 삭제됩니다.

## 폴더 구조

```
src/
  app/
    page.tsx                 홈
    new/page.tsx             시험 설정 + 업로드
    set/[id]/page.tsx        학습 화면
    set/[id]/review/page.tsx 복습 화면
    api/parse                파일 → 페이지별 텍스트
    api/analyze              자료 구간 → 전략 + 개념
    api/quiz                 개념 → 시험 유형별 문제
    api/grade                약술/서술/단답 AI 채점
    api/health               API Key 설정 여부
  components/study/          요약·카드·빈칸·테스트·대시보드·분석 패널
  lib/
    claude.ts   Anthropic API 호출 + 오류 처리 (서버 전용)
    parse.ts    PDF/PPTX/TXT 텍스트 추출 (서버 전용)
    prompts.ts  AI 지시문
    schemas.ts  AI 응답 JSON 스키마
    progress.ts 암기 상태·우선순위·통계
    store.ts    IndexedDB 저장
```

## 알려진 한계

- 자료 분석 중 오류가 나면 "이어서 분석"으로 남은 구간부터 다시 진행할 수 있습니다.
- 시험 직전 압축 복습 모드, 기출 경향 심화 분석(Phase 3)은 아직 구현되지 않았습니다.
